# Decouple

The complete settlement workspace for separating couples in England and Wales.

This repository is between two generations of the product. The first prototype is
archived; the work done in Claude Design is arriving and will become the main work.

| Folder | What it is |
|---|---|
| `archive/prototype-01/` | The first prototype, frozen on 13 October 2026. Complete and runnable on its own: `cd archive/prototype-01 && npm ci && npm run dev`. Its own README, CLAUDE.md and docs apply inside it. |
| `incoming/` | A quarantine for the Claude Design export. Read `incoming/README.md` before adding or taking anything. |
| the root | Reserved for the new main work. Until it has a build, `vercel.json` skips every deployment and no CI runs here. |

The tag `prototype-01-root-layout` marks the last commit with the prototype at the root.
