Look and feel

One treatment for the guide and the help page, for everyone. “As designed” uses each page’s own Tweaks choice. A link with ?theme= still overrides this. The holding page and the toolkit keep their own look.

Tester codes

Each code is for one person. Its label becomes their participant ID in Results. With no prototypes, the code opens the guide. With prototypes, its link opens the participant hub (Take part): consent, a short screener, then only the prototypes you chose. Turning a code off stops it working within a minute.
