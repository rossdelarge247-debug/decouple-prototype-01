# Export 2026-10-19c

Replaces `site/` entirely, following `SYNC.md`. Adds the guide as a PDF attached to the guide email (opt-in). PR name: `sync: design export 2026-10-19c`. `EXPORT.json` names `2026-10-19b` as previous. If 19b, 19a or 18a haven't landed, this one includes them. Their spec changes (`/about`) still need building.

## The spec (`docs/SITE-SPEC.md`, replaces the repo's copy)
- **§7, `POST /api/email`:** an optional `pdf` flag in the body, and `{pdf: true|false}` in the response when it was asked for.
- **§7, the guide email:** the template adds "A PDF copy of your guide is attached." only when it is.
- **§7, new section "The guide PDF":** open `link` with `?print=pdf` before the `#` in headless Chromium (131 or later), wait for `window.__printReady`, and print as A4 with `preferCSSPageSize`. It must render in either site mode without a session, and the headless page may only load `SITE_ORIGIN`. The file is `Your guide.pdf`, under 5 MB, sent with the same fixed template. If it fails, send the link email anyway with `{pdf:false}`. Nothing is stored and the link isn't logged. 20 PDFs an hour across all visitors.

## Changed in `site/`
- **New: `m02/guide/g-print.jsx` + `m02/guide/g-print.css`.** The print layout: a discreet cover ("Your guide", the date), a contents page, one chapter per page, and page numbers through CSS `@page` margin boxes. No buttons or screen-only parts. The safety answers are removed before rendering. With `?print=pdf` it shows only this layout and sets `window.__printReady = true` once fonts and layout have settled. With no guide in the link it sets `window.__printError = "no-guide"`.
- **`Marketing 02 · Divorce Guide.html`:** loads both new files. `?print=pdf` renders the print page instead of the app (no session call, no sending, nothing saved). "Download or print" prints the same layout.
- **`m02/guide/g-guide.jsx` + `g.css` + `g-themes.css`:** the email dialog has an "Attach a PDF copy" tick box, off by default. It sends `pdf: true`, and shows a note when the response has `pdf: false`.
- **`shared/dc-site.js`:** `/api/email` waits 45 s when `pdf` is true (9 s otherwise).
- **`privacy.html`:** the guide email row covers the PDF: built from their link at that moment, nothing kept, no safety answers, and no other company involved.

No new outside hosts. No renamed or removed files.

## Check
- `/guide?print=pdf#g=<a real link's hash>` shows the cover, contents and chapters, and `window.__printReady` becomes true. `/guide?print=pdf` with no hash sets `__printError`.
